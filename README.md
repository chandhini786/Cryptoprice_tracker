# Cryptocurrency Price Tracker

A simple web application built using Python and Flask that displays real-time cryptocurrency prices using the CoinGecko API.

## Features
- Real-time cryptocurrency prices
- Top 10 cryptocurrencies
- Flask web application
- Clean HTML and CSS interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- CoinGecko API

## Project Structure

Cryptoprice_tracker/
├── app.py
├── templates/
│   └── index.html
└── static/
    └── style.css

## How to Run

pip install flask requests

python app.py
